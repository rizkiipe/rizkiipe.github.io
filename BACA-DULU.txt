UPLOAD MUDAH (tanpa folder tersembunyi)

1. Hapus dulu isi lama repo (terutama folder android/ lama, .well-known/, dan .github/ lama).
2. Upload SEMUA isi paket ini (isi foldernya, bukan foldernya) ke repo, commit.
3. Di GitHub, buka dot-github/workflows/build-apk.yml > ikon pensil (Edit).
   Di kotak nama file paling atas, hapus "dot-github" lalu ketik ".github"
   sehingga jadi  .github/workflows/build-apk.yml  > Commit changes.
4. (Disarankan) Add file > Create new file, nama: .nojekyll  > Commit.
5. Lanjut ke README.md langkah 3.
